## Overview

This repository contains short, rough Python practice notebooks written during lectures and self-study sessions. The notebooks are personal working notes that cover core Python concepts from first principles, often applying them to simple financial and data examples to reinforce understanding.

---

## Topics Covered

- String indexing, slicing and concatenation
- Data types — integers, floats, strings, booleans
- Type checking and type conversion (`type()`, `int()`, `float()`, `str()`)
- Lists, tuples, dictionaries and sets
- Sorting with `sorted()` in ascending and descending order
- Conditional logic — if / elif / else statements
- Loops — for and while
- Defining and calling functions (`def`)
- f-strings and formatted output
- Continuous, discrete and binary data types applied to financial contexts
- Buy/sell signal logic using boolean and integer flags
- Importing and using **NumPy** (`np.mean`)
- Importing and using **Pandas** (`pd.read_csv`)
- File system navigation with the `os` module (`os.getcwd`, `os.listdir`)

---

## Context

These notebooks are not polished projects. They are short working notes and quick exercises written to practise and memorise Python syntax during the MSc programme. They complement the main project repositories where full assessments and structured analysis are stored.
